## 💡 使用建议

### 选择模型

**使用CosyVoice2当**:
- ✅ 需要最高音质
- ✅ 做内容创作或专业应用
- ✅ 预算和时间充足

**使用Qwen3-TTS当**:
- ✅ 需要快速响应
- ✅ 做实时应用或API服务
- ✅ 硬件资源有限
- ✅ 多语言场景

### 调整参数

**提升音质**:
```python
# 降低温度增加稳定性
{"text": "...", "temperature": 0.1}

# 调整语速
{"text": "...", "speed": 0.9}  # 放慢
```

**提升速度**:
```python
# 使用Qwen3而非CosyVoice2
{"text": "...", "model": "qwen3"}

# 增加并发数
MAX_WORKERS=8
```

### 集成最佳实践

```python
# 1. 验证输入
if len(text) > 5000:
    raise ValueError("文本过长")

# 2. 使用错误处理
try:
    result = synthesize(text)
except Exception as e:
    logger.error(f"合成失败: {e}")
    # 返回备选方案或错误提示

# 3. 缓存结果
cache[text] = result

# 4. 监控性能
start = time.time()
result = synthesize(text)
elapsed = time.time() - start
logger.info(f"合成耗时: {elapsed:.2f}s")
```

## 📞 常见问题

**Q: 可以用CPU运行吗？**
A: 可以，但速度会很慢。在`config.py`改为`device="cpu"`。

**Q: 支持流式输出吗？**
A: 当前不支持，但可以扩展WebSocket端点。

**Q: 如何处理超长文本？**
A: 分割成短句，分别合成再拼接。见文档导航和快速参考.md。

**Q: 能否微调模型？**
A: CosyVoice2支持，需要标注数据。见官方仓库。

**Q: 商用需要许可吗？**
A: 请检查具体模型的许可证。CosyVoice2是开源的。
