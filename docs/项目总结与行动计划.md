## 💡 核心特性说明

### 1. 多模型支持

**CosyVoice2** (推荐用于中文)
- MOS: 5.53 (业界最高)
- 优点: 最高质量、多模式、音色自然
- 缺点: 推理时间稍长 (~2s)
- 模式: SFT(预定义说话人) | Zero-shot(语音克隆) | Instruct(指令)

**Qwen3-TTS** (多语言均衡)
- 优点: 多语言、推理快(~1s)、WER最低(1.24%)
- 缺点: 音质略低于CosyVoice2
- 用途: 英文、多语言应用

**运行时切换**:
```python
# 在API请求中指定
{
    "text": "你好世界",
    "model": "cosyvoice2",  # 或 "qwen3"
}

# 或在.env中设置默认
DEFAULT_TTS_MODEL=cosyvoice2
```

### 2. MFA字级对齐

**工作流程**:
```
生成音频 → 保存临时文件 → MFA强制对齐 → 解析TextGrid → 返回时间戳
```

**精度**: 85-95% (取决于音频质量)

**降级方案**: 当MFA失败时，自动使用均匀分配方案

**输出格式**:
```json
{
  "alignments": [
    {"char": "你", "start": 0.0, "end": 0.45, "confidence": 0.92},
    {"char": "好", "start": 0.45, "end": 0.9, "confidence": 0.91}
  ]
}
```

### 3. 灵活的输出格式

```python
# 选项1: Base64编码 (推荐用于API)
"output_format": "base64"
# 返回: "UklGRi4AAAA..."

# 选项2: URL (推荐用于大文件)
"output_format": "url"
# 返回: "/audio/abc123.wav"

# 选项3: 两者都返回
"output_format": "both"
```

### 4. 环境变量与运行时参数

**优先级**: 运行时参数 > 环境变量 > 默认值

```python
# 例如，虽然.env设置了CosyVoice2，但这个请求使用Qwen3
curl -X POST http://localhost:8000/synthesize \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello",
    "model": "qwen3"  # 覆盖.env配置
  }'
```

### 需求5: 批量处理

**示例**:
```python
# batch_process.py
import requests

class BatchProcessor:
    def __init__(self, api_url="http://localhost:8000"):
        self.api_url = api_url
    
    def process_file(self, input_file, output_dir):
        """处理文本文件"""
        with open(input_file, 'r', encoding='utf-8') as f:
            sentences = f.readlines()
        
        results = []
        for idx, sentence in enumerate(sentences):
            response = requests.post(
                f"{self.api_url}/synthesize",
                json={"text": sentence.strip()}
            )
            
            result = response.json()
            results.append(result)
            
            # 保存音频
            if result['status'] == 'success':
                audio_base64 = result['data']['audio']
                audio_bytes = base64.b64decode(audio_base64)
                
                output_file = f"{output_dir}/audio_{idx:04d}.wav"
                with open(output_file, 'wb') as f:
                    f.write(audio_bytes)
        
        return results

# 使用
processor = BatchProcessor()
results = processor.process_file("input.txt", "output_audio")
```

## 🐛 故障排查速查表

| 问题 | 原因 | 解决 |
|------|------|------|
| ModuleNotFoundError: cosyvoice | CosyVoice未安装 | `git clone + pip install -e .` |
| CUDA out of memory | 模型太大或并发太多 | 用小模型、降低MAX_WORKERS |
| MFA align timeout | 对齐时间过长 | 增大MFA_TIMEOUT或使用降级方案 |
| 时间戳精度低 | MFA模型不匹配 | 检查`mfa model list` |
| API响应慢 | 模型加载或推理 | 使用更快的模型或优化硬件 |

```python
# 添加API密钥验证
@app.middleware("http")
async def verify_api_key(request: Request, call_next):
    api_key = request.headers.get("X-API-Key")
    if api_key != os.getenv("API_KEY"):
```
