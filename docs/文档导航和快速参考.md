### MFA对齐工作流

```
输入: 文本 "你好" + 音频波形
   ↓
保存临时文件
   ↓
运行MFA强制对齐
   ↓
解析TextGrid格式
   ↓
输出: [{"char": "你", "start": 0.0, "end": 0.45}, ...]
```

**关键**: MFA精度取决于音频质量和模型训练数据匹配度

```bash
curl -X POST http://localhost:8000/synthesize \
  -H "Content-Type: application/json" \
  -d '{
```

```python
    "text": "Hello",

```

### 任务3: 调整语速

```python
{
    "text": "你好",
    "model": "cosyvoice2",
    "speed": 1.5  # 加速1.5倍 (0.5-2.0)
}
```

### 任务4: 语音克隆

```python
# 1. 上传参考音频
files = {'file': open('reference.wav', 'rb')}
response = requests.post("http://localhost:8000/upload_audio", files=files)
file_id = response.json()['data']['file_id']

# 2. 使用克隆模式合成
{
    "text": "合成新句子",
    "model": "cosyvoice2",
    "mode": "zero_shot",
    "prompt_audio": f"temp_audio/{file_id}_reference.wav",
    "prompt_text": "参考音频中的原文"
}
```

### 任务5: 获取时间戳

```python
# 直接从响应中提取
result = response.json()
alignments = result['data']['alignments']

# alignments格式
[
    {"char": "你", "start": 0.0, "end": 0.45, "confidence": 0.92},
    {"char": "好", "start": 0.45, "end": 0.9, "confidence": 0.91}
]
```

### 任务6: 生成字幕

```python
from alignment.textgrid_parser import SRTGenerator, VTTGenerator

# 生成SRT格式
SRTGenerator.generate(alignments, "output.srt")

# 生成VTT格式 (用于HTML5 video)
VTTGenerator.generate(alignments, "output.vtt")
```

### 任务7: 批量处理

```python
import concurrent.futures

texts = ["你好", "世界", "测试"]

def synthesize_one(text):
    return requests.post(
        "http://localhost:8000/synthesize",
        json={"text": text}
    ).json()

# 并发处理
with concurrent.futures.ThreadPoolExecutor(max_workers=4) as executor:
    results = executor.map(synthesize_one, texts)
```

## 🔍 故障排查速查

### ❌ "ModuleNotFoundError: No module named 'cosyvoice'"

**解决**: 从源码安装
```bash
git clone https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice
pip install -e .
```

### ❌ "CUDA out of memory"

**解决**: 降低显存占用
```bash
# .env配置
QWEN3_DTYPE=float16              # 使用float16
MAX_WORKERS=2                    # 降低并发
COSYVOICE_MODEL_DIR=...0.5B      # 使用小模型
```

### ❌ "MFA align failed"

**解决**: 检查模型下载
```bash
mfa model list
# 如果缺少模型，运行：
mfa model download acoustic chinese_flac
mfa model download dictionary chinese_flac
```

### ❌ "Time alignment is low quality"

**可能原因**:
1. 音频质量差 → 检查输入音频
2. MFA模型不匹配 → 用中文模型处理中文文本
3. 文本含特殊符号 → 预处理文本

**解决**: 检查`confidence`字段 (>0.8 = 高质量)

### ❌ "API响应超时"

**原因**: 文本过长或硬件性能差

**解决**:
```python
# 分割长文本
def split_text(text, max_len=50):
    return [text[i:i+max_len] for i in range(0, len(text), max_len)]

# 使用Qwen3而非CosyVoice2 (更快)
{"text": sentence, "model": "qwen3"}
```

### 示例项目集成

**Flask集成示例**:
```python
from flask import Flask, request, jsonify
import requests

app = Flask(__name__)
TTS_API = "http://localhost:8000"

@app.route('/api/speak', methods=['POST'])
def speak():
    text = request.json.get('text')
    response = requests.post(f"{TTS_API}/synthesize", json={"text": text})
    return response.json()
```

**Django集成示例**:
```python
# views.py
import requests
from django.http import JsonResponse

def synthesize_view(request):
    text = request.POST.get('text')
    response = requests.post(
        "http://localhost:8000/synthesize",
        json={"text": text}
    )
    return JsonResponse(response.json())
```

**前端HTML5示例**:
```html
<!DOCTYPE html>
<html>
<head>
    <title>TTS演示</title>
</head>
<body>
    <input type="text" id="text" placeholder="输入文本">
    <button onclick="synthesize()">合成语音</button>
    <video id="video" controls style="margin-top: 20px;">
        <track kind="captions" src="captions.vtt">
    </video>

        async function synthesize() {
            const text = document.getElementById('text').value;
            const response = await fetch('http://localhost:8000/synthesize', {
                method: 'POST',
                headers: {'Content-Type': 'application/json'},
                body: JSON.stringify({text, model: 'cosyvoice2', output_format: 'base64'})
            });
            
            const result = await response.json();
            const audio = new Audio('data:audio/wav;base64,' + result.data.audio);
            audio.play();
        }
```
